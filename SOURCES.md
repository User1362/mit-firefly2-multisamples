# Sources and credits

Every instrument is a render of one factory preset of **Firefly Synth 2 v2.1.6** by Sjoerd van Kreel (https://github.com/sjoerdvankreel/firefly-synth-2, tag `v2.1.6`, commit `f029433ca7c7d7685488fb60cb8e29dddc0ceeda`), license MIT (see `LICENSE`).

Rendering: Windows VST3 release `FireflySynth2-windows-vst3-Release.zip` (SHA-256 `40a5d4f1d94e3f644bc59985b22432f8de4c71491af6ba47dec2401bcae7d9a3`), preset state (`patchState` of the `.ff2preset` file) loaded as the plugin component state, MIDI keys 36/48/60/72/84, velocity 100, key held 4.0 s, trimmed to 5.5 s, 48 kHz, 24-bit FLAC. Level matched so the loudest 0.5 s window of each sample sits at -20 dBFS (clipped to a -1 dBFS peak); the gain is stored in the SFZ `volume`.

The preset files do not carry per-preset author or license fields; the license is that of the repository at the pinned commit.
